# README.md

VCOO Onboarding scaffold: backend FastAPI + frontend React (Vite). Use this project as a starting point for building the onboarding and OAuth-based authflow for MAGI / VCOO instances.

Local run:

- Copy .env.example to .env and set MASTER_KEY
- docker-compose up --build
- Backend: http://localhost:8000
- Frontend: (por implementar) http://localhost:3000

Todos los puntos importantes se marcan con TODO en el código.
