# Documentación del Cliente

Coloca aquí la documentación interna de tu empresa:
- Manuales de procedimientos
- FAQs y guías
- Tarifas y precios
- Plantillas de documentos
- Reglas de negocio

Estructura sugerida:
```
docs/
├── manuales/        # Procedimientos operativos
├── faq/             # Preguntas frecuentes
├── tarifas/         # Precios y servicios
├── plantillas/      # Documentos reutilizables
└── reglas/          # Reglas de automatización
```

MAGI leerá estos documentos para entender tu negocio.
